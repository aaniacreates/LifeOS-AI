# LifeOS AI - Project Statement

## Problem Statement

Students often track study time, sleep, screen time, exercise, mood, stress, and daily tasks separately or do not track them consistently. This makes it difficult to review routine patterns in one place.

LifeOS AI provides a simple command-line system where a student can enter selected daily-life data, receive a rule-based productivity score, review previous records, generate a recent-period report, and identify simple recurring patterns.

## Scope of the Project

The project covers:

- Daily student-life data entry
- Input validation
- Productivity score calculation
- Daily analysis
- Historical record viewing
- Recent seven-record reporting
- Rule-based trend insights
- CSV-based local storage
- Basic automated tests

The current project does not include a graphical interface, cloud storage, external APIs, or a trained machine-learning model.

## Target Users

The primary target users are students who want a simple command-line method for reviewing their daily routine data.

## High-Level Features

1. Daily Data Entry
